01 Sehen

Sieh, welche Agenten auf dich warten

Die Seitenleiste bündelt deine Chats. Das „Agenten-Büro“ zeigt jeden Agenten als Pixel-Art-Figur mit seinem aktuellen Status.

  • Die Seitenleiste zeigt, welche Chats arbeiten und welche auf dich warten (mit einem „!“), samt Zähler „N brauchen dich“.
  • Wenn das Fenster im Hintergrund ist und ein Agent dich etwas fragt, zeigt macOS eine Mitteilung. Das Dock-Symbol zeigt die Zahl der wartenden Chats.
  • Wenn ein Durchlauf fertig ist, meldet macOS „fertig“. Du kannst das im App-Menü unter „Benachrichtigen, wenn Agent fertig ist“ ausschalten. Mitteilungen zu Fragen bleiben aktiviert.
  • Nach jedem Durchlauf listet ein Block die bearbeiteten Dateien auf. Klicke auf eine Datei, um sie in der rechten Spalte zu öffnen.

02 Genehmigen

Direkt in der App genehmigen

Berechtigungsanfragen von Claude Code, Codex und Antigravity erscheinen als Karten in der App. Antworte direkt dort.

  • Bei Dateiänderungen zeigt die Karte entfernte und hinzugefügte Zeilen.
  • Auch Fragen und Pläne von Claude Code erscheinen dort, damit du antworten kannst.
  • Auch Fragen von einem Claude-Sub-Agent im Hintergrund werden angezeigt.

    03 Stoppen

    Einen laufenden Durchlauf stoppen

    Wenn ein Agent in die falsche Richtung läuft, stoppe den Durchlauf direkt in der App. Probier es aus und klicke in dieser Demo auf „Stoppen“.

    • Du kannst einen laufenden Durchlauf stoppen.
    • Ein gestoppter Durchlauf wird mit „Dieser Durchlauf wurde gestoppt.“ markiert.
    • Bei einem fehlgeschlagenen Durchlauf wird der vom Anbieter gemeldete Grund angezeigt.

      04 Fortfahren

      Während eines Durchlaufs weitere Nachrichten senden

      Du musst nicht warten, bis ein Durchlauf fertig ist, um weiterzuschreiben. Auch beim Neuladen der Seite geht der Durchlauf nicht verloren.

      • Sende eine weitere Nachricht, während ein Durchlauf läuft.
      • Lade die Seite neu, ohne den laufenden Durchlauf zu verlieren.
      • Für jeden Chat kannst du Laufzeit (Claude Code, Codex oder Antigravity), Modell und Aufwand separat wählen.
      • Ein Chat-Entwurf wird beim Anbieter erst mit der ersten Nachricht angelegt.
      • Bearbeite eine gesendete Nachricht oder zweige von einer Nachricht ab, um eine andere Richtung auszuprobieren.
      • Hänge Bilder, PDFs und Textdateien an. Aktiviere oder deaktiviere MCP-Server direkt im Eingabefeld.
      So funktioniert es

      Die App läuft direkt auf deinem Rechner

      Die App ist ein natives Fenster mit einer Webseite, die auf deinem Rechner läuft. Ein kleiner Server stellt diese Seite bereit, und die App startet den Server selbst. Der Server kommuniziert direkt auf deinem Rechner mit den Tools der Anbieter.

      • Wenn du einen Chat oder Ordner in der App entfernst, wird beim Anbieter nichts gelöscht.

      Kurze Fragen

      Sechs häufige Fragen

      Braucht die App ein eigenes Konto?

      Nein. Sie verwendet Claude Code, Codex und Antigravity, die bereits auf deinem Gerät installiert und angemeldet sind, und ruft keine Modell-API auf.

      Sendet die App meinen Code irgendwohin?

      Deine Claude Code-, Codex- oder Antigravity-Tools senden Chat-Inhalte, nicht die App. Jeder Durchlauf läuft über die Tools des Anbieters. Der Server der App lauscht nur auf 127.0.0.1.

      Wird ein Chat beim Anbieter gelöscht, wenn ich ihn in der App entferne?

      Nein. Wenn du in der App einen Chat oder Ordner entfernst, wird beim Anbieter nichts gelöscht.

      Was schreibt die App außerhalb ihres Datenordners?

      Nur, wenn du es anforderst. Wenn du zum Beispiel unter „Statusquelle“ auf „Hook installieren“ klickst, fügt die App einen Beobachtungs-Hook zu ~/.claude/settings.json (Claude Code) oder ~/.gemini/config/hooks.json (Antigravity) hinzu. „Hook entfernen“ entfernt ihn wieder.

      Wie deinstalliere ich die App?

      Wenn du auf „Hook installieren“ geklickt hast, klicke zuerst auf „Hook entfernen“. Beende die App und ziehe Agent Workspace aus „Programme“ in den Papierkorb. Um auch die Daten zu entfernen, lösche ~/Library/Application Support/Agent Workspace.

      Wo kann ich einen Fehler melden?

      Erstelle ein Issue unter Issues auf GitHub. Nenne die Versionen der App und von macOS, den Anbieter des Chats, deine Schritte und was du gesehen hast. Füge keine Token oder vertraulichen Chat-Inhalte ein.
