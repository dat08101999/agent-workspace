01 Ver

Veja quais agentes estão aguardando você

A barra lateral reúne seus chats. O “Escritório de agentes” mostra cada agente como um personagem pixel art que reflete seu status real.

  • A barra lateral mostra quais chats estão trabalhando e quais aguardam você (com o sinal “!”), além de um contador “N precisam de você”.
  • Quando a janela está em segundo plano e um agente faz uma pergunta, o macOS mostra uma notificação; o ícone do Dock mostra o número de chats aguardando.
  • Quando um turno termina, o macOS avisa “concluído”. Você pode desativar isso no menu do app, em “Notificar quando o agente terminar”; as notificações de perguntas continuam ativadas.
  • Depois de cada turno, um bloco lista os arquivos editados. Clique em um arquivo para abri-lo na coluna à direita.

02 Aprovar

Aprove no app

Solicitações de permissão do Claude Code, Codex e Antigravity aparecem como cartões no app. Responda ali mesmo.

  • Para edições de arquivos, o cartão mostra as alterações como linhas removidas e adicionadas.
  • As perguntas e os planos do Claude Code também aparecem ali para você responder.
  • Perguntas de um subagente do Claude em execução em segundo plano também aparecem.

      04 Continuar

      Envie outra mensagem durante um turno

      Você não precisa esperar um turno terminar para continuar, e recarregar a página não fará esse turno ser perdido.

      • Envie outra mensagem enquanto um turno está em andamento.
      • Recarregue a página sem perder o turno em andamento.
      • Cada chat tem sua própria escolha de runtime (Claude Code, Codex ou Antigravity), modelo e esforço.
      • Um chat em rascunho não cria nada no provedor até a primeira mensagem.
      • Edite uma mensagem enviada ou bifurque a conversa a partir de uma mensagem para tentar outra direção.
      • Anexe imagens, PDFs e arquivos de texto; ative ou desative servidores MCP no campo de mensagem.
      Como funciona

      O app roda no seu próprio computador

      O app é uma janela nativa com uma página web executada no seu computador. Um pequeno servidor fornece essa página, e o próprio app inicia o servidor. O servidor se comunica com as ferramentas dos provedores no seu computador.

      • O token local, o banco de dados e os logs ficam em ~/Library/Application Support/Agent Workspace.
      • Remover um chat ou uma pasta no app não apaga nada no provedor.
      Instalar

      Instale Agent Workspace

      Um ZIP com o app para Mac assinado e notarizado. O servidor está incluído; não é preciso instalar .NET nem Node.

      O que você precisa

      • Um Mac com Apple silicon e macOS 12 ou posterior.
      • python3 no seu computador. A versão do Xcode Command Line Tools é suficiente; se não tiver, execute xcode-select --install.
      • Pelo menos uma ferramenta instalada e com sessão iniciada: Claude Code, Codex ou Antigravity.

      Perguntas rápidas

      Seis perguntas frequentes

      O app precisa de uma conta própria?

      Não. Ele usa Claude Code, Codex e Antigravity já instalados e conectados na sua máquina, e não chama nenhuma API de modelo.

      O app envia meu código para algum lugar?

      São suas próprias ferramentas Claude Code, Codex ou Antigravity que enviam o conteúdo dos chats, não o app. Cada turno é executado pelas ferramentas do provedor. O servidor do app escuta apenas em 127.0.0.1.

      Remover um chat no app o exclui do provedor?

      Não. Remover um chat ou uma pasta no app não exclui nada no provedor.

      O que o app grava fora da pasta de dados?

      Só quando você pede. Por exemplo, clicar em “Instalar hook” em “Fonte de status” adiciona um hook de observação a ~/.claude/settings.json (Claude Code) ou ~/.gemini/config/hooks.json (Antigravity). “Remover hook” o remove.

      Como faço para desinstalar?

      Se você clicou em “Instalar hook”, clique primeiro em “Remover hook”. Encerre o app e arraste Agent Workspace de Aplicativos para o Lixo. Para remover também os dados, exclua ~/Library/Application Support/Agent Workspace.

      Onde relato um bug?

      Abra uma issue em Issues no GitHub. Inclua as versões do app e do macOS, o provedor do chat, as etapas que você seguiu e o que viu. Não cole tokens nem conteúdo confidencial de chats.
