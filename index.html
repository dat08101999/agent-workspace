01 See

See which agents are waiting for you

The sidebar brings your chats together. “Agent Office” draws each agent as a pixel-art character that reflects its real status.

  • The sidebar shows which chats are running and which are waiting for you (the “!” mark), with an “N need you” counter.
  • When the window is in the background and an agent asks you something, macOS shows a notification; the Dock icon shows the number of waiting chats.
  • When a turn finishes, macOS says “done”. You can turn this off in the app menu under “Notify when Agent finishes”; question notifications stay on.
  • After each turn, a block lists the edited files. Click a file to open it in the right column.

      How it works

      The app runs on your own machine

      The app is a native window containing a web page running on your machine. A small server serves that page, and the app starts the server itself. The server talks to the providers' tools on your machine.

      On your Mac
      App windowA native window with a web page running on your machine inside.
      Local server127.0.0.1:5188Started by the app, listening only at this address.
      Claude Code · Codex · AntigravityTools already installed and signed in on your machine.
      ProviderYour own tools send chat content, not the app.
      • The app has no account of its own and calls no model API.
      • Every turn runs through the provider's tools.
      • The local token, database and logs are in ~/Library/Application Support/Agent Workspace.
      • Removing a chat or folder in the app deletes nothing at the provider.

      Quick questions

      Six common questions

      Does the app need its own account?

      No. It uses Claude Code, Codex and Antigravity already installed and signed in on your machine, and calls no model API.

      Does the app send my code anywhere?

      Your own Claude Code, Codex or Antigravity tools send chat content, not the app. Every turn runs through the provider's tools. The app's server listens only on 127.0.0.1.

      Does removing a chat in the app delete it at the provider?

      No. Removing a chat or folder in the app deletes nothing at the provider.

      What does the app write outside its data folder?

      Only when you ask. For example, clicking “Install hook” under “Status source” adds an observation hook to ~/.claude/settings.json (Claude Code) or ~/.gemini/config/hooks.json (Antigravity). “Remove hook” removes it.

      How do I uninstall it?

      If you clicked “Install hook”, click “Remove hook” first. Quit the app, then drag Agent Workspace from Applications to the Trash. To remove its data too, delete ~/Library/Application Support/Agent Workspace.

      Where do I report a bug?

      Open an issue in Issues on GitHub. Include the app and macOS versions, the chat's provider, the steps you took and what you saw. Don't paste tokens or sensitive chat content.
