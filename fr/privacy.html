Agent Workspace

Confidentialité

Agent Workspace ne collecte aucune donnée

Dernière mise à jour : 17 octobre 2026

Agent Workspace est une app pour votre Mac, accompagnée d’une app pour votre iPhone. Elle ne nécessite aucun compte et n’utilise aucun de nos serveurs. Nous ne collectons, ne recevons, ne stockons ni ne vendons aucune information vous concernant ou concernant votre utilisation de l’app. Il n’y a ni analyse d’utilisation, ni publicité, ni suivi.

Sur votre Mac

  • L’app conserve ses propres données (une base de données locale, des logs et un jeton d’accès local) sur votre Mac, dans ~/Library/Application Support/Agent Workspace. Son serveur local écoute uniquement sur 127.0.0.1.
  • Vos conversations s’exécutent dans les outils de programmation que vous avez installés (Claude Code, Codex, Antigravity), avec vos propres comptes chez ces fournisseurs. Agent Workspace n’appelle lui-même aucune API de modèle ; les données que ces outils envoient à leurs fournisseurs sont régies par leurs propres politiques de confidentialité.
  • Au démarrage, l’app ajoute une entrée nommée pet_task_manager à la configuration de chacun de ces outils, afin qu’une conversation puisse utiliser les outils de l’app. Elle sauvegarde le fichier avant de le modifier et ne réajoute pas l’entrée si vous la supprimez.

Sur votre iPhone

  • L’app iPhone communique uniquement avec votre Mac : directement, via HTTPS, lorsque les deux appareils sont sur le même réseau ; sinon, via votre propre compte iCloud, dans la base de données privée du conteneur iCloud de l’app, où les messages sont conservés dans des champs chiffrés. Apple stocke ces données iCloud selon sa politique de confidentialité ; nous n’y avons pas accès.
  • Les notifications concernant une conversation arrivent sur votre iPhone via votre iCloud. Elles indiquent uniquement le type d’événement et le nom de la conversation, jamais ce qu’un agent ou vous avez écrit.
  • Sur iPhone, l’app conserve ses réglages (apparence claire ou sombre, dossiers ouverts), la dernière liste de conversations pour l’afficher immédiatement, ainsi que le moyen de joindre votre Mac. Supprimer l’app supprime ces données.
  • Les photos et fichiers que vous joignez sur iPhone vont uniquement vers votre propre Mac, directement via votre Wi‑Fi ou par votre propre iCloud, puis vers le fournisseur de la conversation, comme lorsque vous les joignez sur Mac. L’appareil photo n’est utilisé que lorsque vous prenez une photo à joindre ; le sélecteur de photos n’affiche que celles que vous choisissez.
  • Le mode de démonstration (« Essayer avec des données d’exemple ») utilise des données fictives intégrées à l’app et n’envoie rien nulle part.
