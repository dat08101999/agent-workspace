01 Voir

Voir quels agents vous attendent

La barre latérale rassemble vos discussions. Le « Bureau des agents » représente chaque agent par un personnage en pixel art qui reflète son état réel.

  • La barre latérale indique quelles discussions sont en cours et lesquelles vous attendent (le signe « ! »), avec un compteur « N vous attendent ».
  • Quand la fenêtre est en arrière-plan et qu’un agent vous pose une question, macOS affiche une notification ; l’icône du Dock indique le nombre de discussions en attente.
  • À la fin d’un tour, macOS indique « terminé ». Vous pouvez désactiver cette notification dans le menu de l’app, sous « M’avertir quand l’agent a terminé » ; les notifications de question restent activées.
  • Après chaque tour, un bloc répertorie les fichiers modifiés. Cliquez sur un fichier pour l’ouvrir dans la colonne de droite.

02 Approuver

Approuver dans l’app

Les demandes d’autorisation de Claude Code, Codex et Antigravity apparaissent sous forme de cartes dans l’app. Répondez directement depuis cette carte.

  • Pour les modifications de fichiers, la carte présente les changements sous forme de lignes supprimées et ajoutées.
  • Les questions et les plans de Claude Code s’affichent aussi ici pour que vous puissiez y répondre.
  • Les questions d’un sous-agent Claude qui travaille en arrière-plan s’affichent aussi.

      04 Continuer

      Envoyer un message pendant un tour

      Vous n’avez pas besoin d’attendre la fin d’un tour pour ajouter un message, et recharger la page ne fera pas perdre ce tour.

      • Envoyez un autre message pendant un tour en cours.
      • Rechargez la page sans perdre le tour en cours.
      • Chaque discussion a ses propres choix d’environnement d’exécution (Claude Code, Codex ou Antigravity), de modèle et d’effort.
      • Une discussion brouillon ne crée rien chez le fournisseur avant le premier message.
      • Modifiez un message envoyé ou créez une branche à partir d’un message pour essayer une autre direction.
      • Joignez des images, des PDF et des fichiers texte ; activez ou désactivez les serveurs MCP dans le champ de rédaction.

      Questions rapides

      Six questions fréquentes

      L’app a-t-elle besoin de son propre compte ?

      Non. Elle utilise Claude Code, Codex et Antigravity déjà installés et connectés sur votre machine, sans appeler d’API de modèle.

      L’app envoie-t-elle mon code quelque part ?

      Le contenu des discussions est envoyé par vos propres outils Claude Code, Codex ou Antigravity, pas par l’app. Chaque tour passe par les outils du fournisseur. Le serveur de l’app écoute uniquement sur 127.0.0.1.

      Supprimer une discussion dans l’app la supprime-t-il chez le fournisseur ?

      Non. Supprimer une discussion ou un dossier dans l’app ne supprime rien chez le fournisseur.

      Qu’est-ce que l’app écrit en dehors de son dossier de données ?

      Uniquement à votre demande. Par exemple, cliquer sur « Installer le hook » sous « Source de statut » ajoute un hook d’observation à ~/.claude/settings.json (Claude Code) ou à ~/.gemini/config/hooks.json (Antigravity). « Supprimer le hook » le retire.

      Comment désinstaller l’app ?

      Si vous avez cliqué sur « Installer le hook », cliquez d’abord sur « Supprimer le hook ». Quittez l’app, puis faites glisser Agent Workspace depuis Applications vers la Corbeille. Pour supprimer aussi ses données, supprimez le dossier ~/Library/Application Support/Agent Workspace.

      Où signaler un bug ?

      Ouvrez un issue dans Issues sur GitHub. Indiquez les versions de l’app et de macOS, le fournisseur de la discussion, les étapes suivies et ce que vous avez constaté. Ne collez pas de jetons ni de contenu sensible de discussion.
